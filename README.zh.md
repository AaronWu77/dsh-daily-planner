# 今日计划

[English](README.md) | 中文

## 概述

在跨会话的悬浮卡中规划例行和临时任务，无需切换聊天。未完成任务保留原日期，直到你明确顺延或删除。关闭卡片不会结束当天，也不会删除任务。

## 使用方式

[组合补丁](cordis.patch.yml) 添加一个 Host 插件及其浏览器入口。浏览器入口在左侧底部注册排序为 5 的开关，以及一张全局悬浮卡。当前个人配置的额度组件排序为 10。本插件不包含在 DSH 默认配置中；构建不会自动安装或启用运行中 profile 的插件。

打开卡片后添加今日任务或设置例行规则。例行规则支持指定星期，工作日快捷选项为周一至周五。点击开始今天会标记已规划，之后仍可修改。日终逐项完成、删除或明确顺延；该日期没有未完成任务后，才能完成整理。

以前的未完成任务单独显示，不会自动成为今日安排。当天例行任务只生成一次，不回填从未生成过任务的历史日期。删除本次任务不会停止重复规则。顺延与另一实例碰撞时，需要明确确认保留两项。已删除任务可以恢复。上移和下移按该日期的未完成任务排序，跳过已完成任务。

## 配置

Host 验证以下插件字段；这些是公开配置，不可存放秘密。Web 客户端加载器不会向浏览器入口传入 Host 配置，浏览器使用下表中的默认值。Host 中自定义的 refreshIntervalMs、requestTimeoutMs 和 sidebarOrder 不会传递到浏览器。

| 字段 | 默认值 | 含义 |
|---|---|---|
| timeZone | Host 的 Intl 时区 | 新计划采用的日期时区；重新打开时须与已保存计划一致。 |
| refreshIntervalMs | 60000 | 页面可见时的刷新间隔，整数且至少 1000 毫秒。 |
| requestTimeoutMs | 15000 | 浏览器请求超时，整数且至少 1000 毫秒。 |
| sidebarOrder | 5 | 左侧底部入口排序。 |

## 数据与恢复

Host 将一个版本为 1 的聚合记录保存在 daily_planner 存储域中。实际位置由 DSH 的存储后端配置决定；任务不存入会话日志，也不只存于浏览器。写入和每日生成串行执行，只有提交后的状态才显示为已保存。最近 256 个成功操作的回执支持响应丢失后的重试；更早的重试仍会检查版本。

任务和例行规则编辑器保留开始编辑时的版本。并发修改会使过期保存失败，同时保留草稿，并提供明确的“读取最新内容并放弃本次草稿”操作。后台刷新不会悄悄更新草稿版本。重复实例的顺延确认同样保留原操作版本；其他窗口修改计划后，确认会失败，不会覆盖那次修改。不相关的计划变更也可能触发保守的冲突提示。保存等待中或结果不确定时锁定编辑控件；关闭后再打开不会解除锁定。

请求失败时仍显示最近确认的任务状态。顶部状态会区分等待确认、未保存、读取失败和已保存。响应不确定时使用重试保存；相同操作标识防止重复执行。删除是软删除，不会物理清除任务。卡片显示状态和未提交草稿只存在于内存，完整刷新页面后不会保留。

配置时区必须与已保存时区一致。不一致时，插件会在注册 API 或改动数据前拒绝启用；恢复原配置即可重新打开。`occurrence:` 任务 ID 前缀保留给自动生成实例，手工新增不可使用。如果既有数据已经占用了生成 ID，生成器会选择带确定性后缀的空闲 ID，不修改原任务。例行唯一性仍以规则和原始日期为准。

## 验证

安装开发依赖后，在本插件目录执行：

~~~sh
pnpm run check
~~~

该检查运行 TypeScript、确定性源码测试、两端构建及[构建产物验证](scripts/verify-artifacts.mjs)。验证器使用独立临时存储和 Chromium，不修改当前 Web profile。打包通过 prepack 执行相同检查。浏览器可用性及具体验证范围由验证器诊断说明。

## 模型影响

插件不注册工具，也不注入模型上下文。卡片不消耗模型 token，不改变模型的 KV 缓存。它与 Agent 的待办列表和目标独立。

## 已知限制

本地插件面向当前 DSH API，开发依赖使用本地链接。当前 GUI 的完整部署、鉴权和交互验证与产物检查分开进行。不提供多用户或跨设备同步、离线修改队列、固定右栏、AI 管理或自动顺延。插件不暴露独立运行时 invariant companion：唯一权威聚合在提交前验证，浏览器的版本化显示另有测试。
